# Programming Foundations

This repository aims at improving the programming skills and logic behind the foundational understanding of programming and algorithm design from a developer/engineer's perspective.

The learning path ([Become a Programmer: Foundations](https://www.linkedin.com/learning/paths/become-a-programmer-foundations?u=109339402)) goes through several steps over time.

- [ ] Introduction and Programming Fundamentals
- [ ] Beyond the Fundamentals
- [ ] Object Oriented Design
- [ ] Algorithms
- [ ] Data Structures
- [ ] Design Patterns
- [ ] Databases
- [ ] Memory Pointers and Garbage collection 
- [ ] Secure Coding
- [ ] Test Driven Development
- [ ] Software Testing
